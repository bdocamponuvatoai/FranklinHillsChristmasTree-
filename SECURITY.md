# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately through
GitHub's [private vulnerability reporting](https://github.com/bdocamponuvatoai/FranklinHillsChristmasTree-/security/advisories/new).

You can expect an acknowledgement within a few business days. Once the issue is confirmed, a fix
is prioritised and you'll be credited in the advisory unless you prefer otherwise.

## Scope

This is a statically prerendered marketing site with no user accounts, forms, database or
third-party scripts. Security headers (CSP, HSTS, frame and referrer policies) are configured in
`next.config.ts`.
